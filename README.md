# Keyhole VPN — приложение для Windows

VPN-клиент для Windows на протоколе **VLESS** (ядро Xray). Работает на **Windows 7 SP1 и новее** — для старых систем есть отдельная сборка.

Приложение подключается к серверам в нескольких странах, показывает пинг до каждого и позволяет переключаться между ними в один клик. Управление подпиской, баланс и оплата — прямо в приложении.

### Чем отличаются сборки

**Для Windows 10 и 11** — основная версия со свежим ядром Xray 26.3.

**Для Windows 7, 8 и 8.1** — отдельная сборка: современные версии движка используют системные функции, которых в этих Windows просто нет. Здесь взято ядро Xray 1.8.3, последнее совместимое с ними, а библиотеки Visual C++ встроены прямо в программу — **ставить Visual C++ Redistributable не нужно**, даже на систему без обновлений.

## Установка

1. Скачайте нужный файл по ссылке выше.
2. Запустите файл. Windows покажет предупреждение SmartScreen — нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Предупреждение появляется потому, что установщик не подписан платным сертификатом Authenticode, а не потому, что с файлом что-то не так.
3. Пройдите установку и запустите приложение.
4. Войдите в аккаунт — через Telegram или по email.
5. Выберите сервер из списка и нажмите большую круглую кнопку включения.

## Два режима работы на Windows

Переключатель находится на главном экране. Сменить режим можно только при **выключенном** VPN.

### Прокси — режим по умолчанию

Приложение поднимает локальный прокси и прописывает его в системные настройки Windows.

- Не требует прав администратора
- Через VPN идут браузеры и программы, которые используют системный прокси
- Программы, игнорирующие системный прокси (часть игр, отдельные мессенджеры), пойдут напрямую

### Туннель

Создаётся виртуальный сетевой адаптер, и через VPN идёт **весь** трафик компьютера.

- Требует запуска приложения **от имени администратора**
- Подходит, когда нужно завернуть в VPN абсолютно всё

## Что умеет приложение

- Список серверов с индикацией пинга и кнопкой перепроверки
- Отображение статуса подключения и времени текущей сессии
- Автоматическая проверка соединения после подключения: если трафик через сервер не идёт, приложение само выключает прокси и возвращает обычный интернет, а не показывает ложное «подключено»
- Корректное закрытие: при выходе системные настройки прокси возвращаются к исходным, включая параметр «Автоматическое определение параметров»
- Восстановление настроек при следующем запуске, если прошлый сеанс завершился аварийно
- Управление подпиской, баланс, пополнение и промокоды
- Реферальная программа
- Поддержка и тикеты внутри приложения
- Кнопка «Диагностика» — копирует технический лог в буфер обмена для отправки в поддержку

## Частые вопросы

**Windows ругается на файл при запуске.**
Это SmartScreen. Установщик не подписан сертификатом Authenticode — сертификат платный, и пока его нет. Нажмите «Подробнее» → «Выполнить в любом случае».

**Программа установилась, но не запускается — окно не появляется или ошибка о недостающих DLL.**
Скорее всего скачана сборка не под вашу систему. На Windows 7, 8 и 8.1 нужен файл `Keyhole-Setup-Win7.exe` — версия для Windows 10 там не стартует. Удалите установленное и поставьте правильную сборку.

**После закрытия приложения пропал интернет.**
Так вело себя старое приложение: при закрытии окна системный прокси оставался включённым и указывал на уже неработающий адрес. В текущей версии это исправлено — настройки возвращаются при выходе.
Если проблема осталась от старой версии, снимите настройку вручную: **Панель управления → Свойства обозревателя → Подключения → Настройка сети** → убрать галочку **«Использовать прокси-сервер для локальных подключений»**.

**В браузере иногда виден реальный IP, хотя VPN включён.**
Причина — включённое в Windows «Автоматическое определение параметров» (WPAD): часть запросов уходила мимо VPN. В текущей версии приложение отключает его на время работы VPN и возвращает при выходе. Обновитесь до последней версии.

**Приложение пишет «подключено», а сайты не открываются.**
Обновитесь: теперь приложение само проверяет, идёт ли трафик, и при отказе возвращает обычный интернет с понятным сообщением. Если повторяется — переключитесь на другой сервер и отправьте в поддержку лог из раздела **Профиль → Диагностика**.

**Не работает конкретная программа или игра.**
Скорее всего она не использует системный прокси. Переключитесь на режим **Туннель** — для этого запустите приложение от имени администратора.
